# 更新日志 / Changelog

## 1.0.4 — 2026-11-13

### 更改 / Changed

- 模组设置页的左栏、页签和说明面板改为跟随游戏设置菜单的配色（PEAK 3.1 起为深蓝底、米色字），不再停留在旧版的棕色，和右侧的选项格子一致。想要旧外观可打开新选项「经典棕色配色」（1. Layout，重启生效）。旧版游戏没有新配色时自动使用棕色。
- 左栏加宽到 360，右侧选项区跟着右移；搜索框改为与左栏同宽、高度收窄，「搜索」标签固定一行不再被折断压住；筛选下拉框与左栏右缘对齐。
- 工具行第一行三个按钮平分宽度，文字放不下时自动缩小字号，不再溢出按钮。
- 侧栏行收紧：模组行 44 → 30、分区行 34 → 26，间距同步缩小，一屏能看到更多模组。
- 置顶模组左缘的标记改为 2 像素宽的青柠色细线，在蓝、棕两种底色上都醒目，也不会和勾选、选中色混淆。

### 已知限制 / Known limitation

- 跟随游戏配色时，TimeTheme 的夜间配色只认旧棕色，所以夜里这几处不会被它换成夜间色；需要夜间跟色请打开「经典棕色配色」。

---

- The mod settings page's left column, tabs and description panel now follow the game's settings colours (dark blue with cream text since PEAK 3.1) instead of the old brown, matching the option cells on the right. Turn on the new **Classic brown colours** option (1. Layout, restart to apply) to keep the old look. Older game versions without the new colours keep the brown automatically.
- The left column is wider (360) and the options area moves right with it; the search box now matches the column width and is shorter, the "Search" label stays on one line instead of wrapping under the box, and the filter dropdown lines up with the column's right edge.
- The three buttons in the first toolbar row share the width equally and shrink their text when it does not fit, instead of spilling out.
- Tighter sidebar rows: mod rows 44 → 30, section rows 34 → 26, with smaller gaps, so more mods fit on screen.
- The pinned-mod marker is now a 2-pixel lime line, visible on both blue and brown and distinct from the tick and the selection colour.
- Known limitation: with the game colours, TimeTheme's night palette only recognises the old brown, so these parts are not recoloured at night. Turn on **Classic brown colours** if you want them to follow TimeTheme.

## 1.0.3 — 2026-11-11

### 修复 / Fixed

- 适配 PEAK 3.1.0：游戏改了设置页的数字格式后，模组的小数参数显示成整数（0.35 显示为 0），手动输入时小数点还会被吞掉、存成错误的值。现在模组参数最多显示三位小数，输入时保留你敲的内容；游戏自己的设置保持新版的显示方式。
- 内建的 en-us / zh-cn / zh-tw 语言文件被清空或只剩注释时，改用内置译文，不再报「没有一行有效的键=译文」导致语言应用失败。

### 新增 / Added

- 同时装了完整版「游戏内模组管理器」（In-Game Mod Manager）时，日志和设置页说明面板会提示一次：它已包含本模组的全部功能，两个一起开会重复修改设置页，建议只保留一个。只提示，不阻止。

---

- PEAK 3.1.0 support: after the game changed how settings format numbers, mod decimal parameters showed as whole numbers (0.35 showed as 0), and typing a value could drop the decimal point and store the wrong number. Mod parameters now show up to three decimals and keep what you type; the game's own settings keep the new look.
- If the built-in en-us / zh-cn / zh-tw language file is empty or only has comments, the built-in texts are used instead of failing with "no valid key=text line".
- When the full **In-Game Mod Manager** is also installed, the log and the settings-page description panel point it out once: it already includes everything this mod does, and running both changes the settings page twice. Keep only one. This is a notice only; nothing is blocked.

## 1.0.2 — 2026-09-18

### 修复 / Fixed

- 依赖列表里的 XUnity AutoTranslator 换成仍在维护的 `RTLC-XUnity_AutoTranslator-5.6.11`；1.0.1 写的 `Hayrizan-XUnity_AutoTranslator-5.6.1` 在 Thunderstore 上已标记弃用。两个包里的插件本体都是 XUnity 5.6.1，本模组的反射对接不受影响，已装 XUnity 的用户无需操作。

---

- The XUnity AutoTranslator dependency now points at the maintained `RTLC-XUnity_AutoTranslator-5.6.11`; the `Hayrizan-XUnity_AutoTranslator-5.6.1` listed in 1.0.1 is marked deprecated on Thunderstore. Both packages ship the same XUnity 5.6.1 plugin, so the reflection bridge is unaffected and existing installs need no action.

## 1.0.1 — 2026-09-18

### 更改 / Changed

- XUnity AutoTranslator 列入依赖（`Hayrizan-XUnity_AutoTranslator-5.6.1`）：只是让模组管理器一起装上，不装也不会出问题——翻译工具（补漏翻 / 显示原文 / 词典镜像）置灰，其余功能照常。
- 「Disable XUnity machine translation」默认改为**开启**：装有 XUnity 时每次启动清空它的机翻端点（`AutoTranslatorConfig.ini` 的 `Endpoint` / `FallbackEndpoint`），并清空各语言目录的机翻缓存 `_AutoGeneratedTranslations*.txt`（每个文件旁留一份 `.bak`）。依赖在线机翻的话请在首次启动前把它关掉。README 与生成的 readme.md 新增「本模组会改动 XUnity AutoTranslator 的一项设置」一节，cfg 选项说明同步。

---

- XUnity AutoTranslator added to the dependency list (`Hayrizan-XUnity_AutoTranslator-5.6.1`) so the mod manager installs it alongside; nothing breaks without it — the translation tools (Untranslated / Show original / dictionary mirroring) are greyed out, everything else works.
- "Disable XUnity machine translation" is now **on by default**: with XUnity installed, every startup empties its machine-translation endpoints (`Endpoint` / `FallbackEndpoint` in `AutoTranslatorConfig.ini`) and the `_AutoGeneratedTranslations*.txt` caches in every language folder (a one-time `.bak` copy is kept). Turn it off before the first launch if you rely on live machine translation. README and the generated readme.md gained a "This mod changes an XUnity AutoTranslator setting" section; the cfg description was updated to match.
