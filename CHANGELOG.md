# 更新日志 / Changelog

## 1.0.0 — 2026-09-18

首个公开版本。开发期（2026-09-11 起的 1.0.0–1.0.42 逐版记录）已归档，不随包附带；源码注释里出现的 1.0.x / 2.x 版本号均指开发期编号。

First public release. The per-build development log (1.0.0–1.0.42 since 2026-09-11) is archived and no longer shipped; version numbers quoted in source comments refer to that development numbering.

### 功能 / Features

- **树形侧栏**：模组列表竖排在左，选中模组在其下方展开分区，右侧显示选项；支持搜索、类型筛选、置顶列、「只看按键」开关、名称 / 加载顺序排序、逐行出现动效与滚轮缓动；筛选时无匹配项的模组行自动隐藏，分区选择按模组记忆。
- **说明面板**：右上常驻面板显示悬停 / 手柄聚焦选项的说明、默认值、范围或可选值；选中模组 / 分区时显示模组名、版本与 manifest 简介；工具行各按钮悬停显示用途注释；可滚动。
- **界面本地化与语言文件**：ModConfig 自带界面（搜索、默认、清空、筛选项、按键提示）与本模组全部文字走语言文件（`BepInEx\config\ModConfigEnhance\language\`），内建 en-us / zh-cn / zh-tw，页面内下拉即时切换；命名规则 `语言码[-变体][_分包].txt`，支持 `// display:` 显示名、组内分包与冲突日志。
- **翻译工具**：导出全部待翻文本 / 只导出未翻条目（查 XUnity 内存词典，精确 / 正则 / 替换都算）；「仅导出已选」列；显示原文 / 译文全局切换；重载翻译；打开目录；选中语言文件时可同步切换 XUnity 的目标语言并镜像词典（可关）。
- **手柄支持**：左栏 / 右栏两级导航（A 进入、B 逐级返回、LB/RB 切模组），显式导航链，滑条须按 A 激活再调值（步进 0.5%，长按加速），下拉 / 输入框 / 按键绑定（长按 1 秒写入）均可用，焦点框与滚动跟随。
- **主题**：借用原版手绘纸面底图与会抖的 `Scouts/UI` 材质；装有 TimeTheme 时整页随昼夜配色。
- **打字保护**：搜索框 / 文本选项聚焦时屏蔽其他模组的键盘轮询，不再误触快捷键。
- **兼容性**：按 ModConfig 1.8.2 与 PEAKLib.UI 1.7.1 逐行核对；目标方法缺失时各补丁自行跳过。

- **Tree sidebar**: vertical mod list on the left, the selected mod's sections expand beneath it, options on the right; search, type filters, a Pin column, a "keybinds only" toggle, name / load-order sorting, row cascade animation and smoothed wheel scrolling; rows with no matches hide while filtering, the chosen section is remembered per mod.
- **Description panel**: persistent panel at the top right showing the hovered / focused option's description, default value, range or choices; a mod / section shows its name, version and manifest summary; toolbar buttons show usage tips; scrollable.
- **UI localization & language files**: ModConfig's own UI (Search, Default, Clear, filters, key prompts) and every text of this mod come from language files (`BepInEx\config\ModConfigEnhance\language\`), built-in en-us / zh-cn / zh-tw, switched instantly from a dropdown on the page; naming `code[-variant][_part].txt` with `// display:` labels, sub-files and conflict logging.
- **Translation tools**: export every text to translate / only the untranslated ones (checked against XUnity's live dictionary — exact, regex and substitutions all count); "Selected only" column; global original ↔ translation toggle; reload; open folder; picking a language file can switch XUnity's target language and mirror the dictionary (optional).
- **Gamepad support**: two-level left / right navigation (A enters, B steps back, LB/RB switch mods), explicit navigation chains, sliders arm with A before adjusting (0.5% steps, hold to accelerate), dropdowns / input fields / keybinds (hold a key for 1 s) all work, focus frame and scroll-into-view.
- **Theme**: borrows the vanilla hand-drawn paper backdrop and the wobbling `Scouts/UI` material; follows TimeTheme's day / night palette when installed.
- **Typing guard**: while the search box or a text option has focus, other mods' keyboard polling is muted so hotkeys don't fire.
- **Compatibility**: checked line by line against ModConfig 1.8.2 and PEAKLib.UI 1.7.1; each patch skips itself if a target method is missing.

### 注意 / Note

- 「Disable XUnity machine translation」**默认关闭**。打开后每次启动清空 XUnity 的机翻端点并清空各语言目录的机翻缓存 `_AutoGeneratedTranslations*.txt`（每个文件旁留一份 `.bak`）。详见 README。
- "Disable XUnity machine translation" is **off by default**. When on, every startup empties XUnity's machine-translation endpoints and the `_AutoGeneratedTranslations*.txt` caches in every language folder (a one-time `.bak` copy is kept). See the README.
