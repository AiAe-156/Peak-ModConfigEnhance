## 三、README.md「语言文件」段落

## 语言文件（整合包 / 多语言的核心）

目录：`BepInEx\config\ModConfigEnhance\language\`（首次启动自动创建）

| 文件 | 说明 |
|---|---|
| `en-us.txt` `zh-cn.txt` `zh-tw.txt` | 内建三种；只建不覆，可随意改；删掉即恢复默认 |
| `_readme.txt` | 中英说明，每次启动重写；`_` 开头的文件不进下拉框 |
| 你自己的 `xx-yy.txt` | 就是「导出翻译」的产物填上译文后改名（小写语言码，如 `de-de.txt`），首行 `// display: 显示名` 可选 |

**一份语言文件 = 本模组界面词条 + 所有模组的选项文本**，格式与 XUnity 词典相同（`键=译文`，`//` 注释，`\n` `\=` 转义，`{0}` 占位符原样）：

- 第一块 `MCE_*`：本模组管的界面文字（键是稳定 ID，**不要翻键**）。
- 之后各模组分块：选项名 / 说明 / 下拉选项的 `英文原文=译文`——这部分**镜像**给 XUnity 去翻设置列表和游戏里所有同文本。

**流程**：导出翻译 → 填译文 → 改名放进 `language\` → 游戏里第三行「刷新」→ 下拉选中。选中那一刻：本模组界面立刻换（只刷 `MCE_` 索引的组件，不动其他文字）；其余行写到 XUnity `Translation\<语言>\Text\ModConfigEnhance_<文件名>.txt` 并调 XUnity 重载——**不用重启**，设置列表和全游戏文本一起换。前提是文件语言码与 XUnity 的 `Language=` 一致（`zh-cn` ↔ `zh` / `zh-CN` 算一致），不一致会在说明面板橙色提示，改 ini 重启一次即可。换语言时先删旧镜像；「重载翻译」（Alt+R）只在手改文件后重读用；「查漏翻」是补漏工具，可选。

**下拉框第一项「跟随游戏语言」**（默认）：按游戏语言用内建的简 / 繁 / 英，其他语言回落英文；镜像同样按游戏语言挑对应内建文件。文件有错（缺等号、没有有效行、文件不存在）会在说明面板用**橙色**带行号提示。

**镜像开关** `Mirror language file to XUnity`（默认开）；关掉则只翻本模组界面、不碰 Translation 目录。卸载本模组后可手动删 `ModConfigEnhance_*.txt`。

**投稿**：翻好的语言文件欢迎寄给作者 AiAe —— 邮箱 `2323086800@qq.com` / QQ 群 `1104320838`，下个版本随包附带。

## 翻译导出

左栏第一排 `导出翻译`：先写本模组的 `MCE_*` 词条块，再把设置页会显示的全部文字（模组名、分区、选项名、说明、下拉选项）按模组分块写成 XUnity 词典格式到 `config\ModConfigEnhance\export\待翻译_<时间>.txt`。`查漏翻`（需 XUnity）只列它当前词典没命中的条目——判定直接问 XUnity 的内存词典，正则 / 替换表都算数。勾 `仅导出已选` 后左栏多一列「导出」复选框（本模组自己永远包含）。翻完按上面「语言文件」的流程改名放进 `language\` 即可（也可以直接扔进 XUnity 的 `Translation\<语言>\Text\` 再点 `重载翻译`，那样只翻文本、不带本模组界面）。自动跳过 KeyCode / 按键名清单与超过 40 项的选项清单。
