// LocalFix 2.16.0 未翻译文本 2026-09-11 00:26
// ── 这是什么 ──
// ModConfig「模组设置」页会显示的全部文字（模组名、分区名、选项名、选项说明、下拉选项），按模组分块，
// 格式与 XUnity AutoTranslator 词典相同：原文=译文。
// ── 怎么用 ──
// 1. 先粗筛：在游戏里勾「仅导出已选」，把不需要翻译的模组去勾，再导出一次，文件会短很多。
// 2. 把译文填在等号右边（可整份交给 AI 翻），不要改动等号左边的任何字符。
// 3. 存成 UTF-8(仅限中文环境)，改名放进 BepInEx\config\Translation\zh\Text\（如 mods_xxx.txt），
//    回到游戏点「重载翻译」（或 Alt+R）即生效。等号右边留空的行会被 XUnity 忽略，留着无妨。
// ── 给翻译者 / AI 的规则 ──
// · // 开头是注释。「// ==== 模组名 (GUID 版本) ====」与「// -- [分区]」只是分块标记，不用翻、不要删。
// · 原文里的 \n 是换行、\= 是等号，译文保持同样写法；数字、单位、按键名、模组名、GUID、路径照抄。
// · 已经是中文、或中英双语（如「快捷键 (Hotkey)」「中文 | English」）的行或模组不用翻，留空或过滤掉即可。
// · 单个键名 / 枚举值（如 A、F1、auto、eu、Left）是下拉框里的选项，一般照抄或留空。
// · 同一句原文全局只出现一次（XUnity 词典是全局的），后面模组里重复的不再列出。
// · 已自动跳过：KeyCode / 按键名清单、超过 40 项的选项清单。
// [查漏翻] 「已翻」按 Translation 目录下所有 .txt 的原文精确匹配；用正则（r: / sr:）覆盖的条目会误报。
//          已含中文的原文按「无需翻译」计，不列出。
// [仅导出已选] 只含左栏「导出」列勾选的 25 个模组。
