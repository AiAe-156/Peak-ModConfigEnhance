- [ ] 选中本模组时，它下面的分区行（1. Layout / 2. Localization）名字也同样上色；切到别的模组分区行恢复正常。
- [ ] 装了 TimeTheme 且入夜后：行名变暖金（#C9A55B），选中态仍是深琥珀，不跟紫色夜字混。

- [ ] 该选项在 XUnity 不在场时静默跳过（无日志、无报错）。
- [ ] `com.aiae.modconfigenhance.cfg` → `3. State`：`Pinned mods` 里**不再有** `Mod Config Enhance`（首启日志可能有「已从置顶集合移除自身行名」）。
- [ ] 给其他模组勾/取消置顶：本模组行始终排在所有置顶行之前。

## 三、搜索 / 筛选行隐藏

- [ ] 搜索框输入「距离」：输入当下左栏就只留有匹配项的模组行（不再需要点别处才隐藏）。
- [ ] 清空搜索词：所有模组行恢复显示，置顶行仍在顶部、顺序不乱。
- [ ] 筛选下拉选「按键」（或勾「只显示快捷键选项」）：没有按键类选项的模组行整行消失；切换回「全部」全部回来。
